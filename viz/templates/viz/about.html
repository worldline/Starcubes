{% load static %} {% comment %} The About dialog, shared verbatim by the two independent page shells: sources/base.html and viz/chart.html. It is a self-contained include — markup, styles and behaviour in one file — because those two trees share no stylesheet, only the CSS custom properties both define (--bg2/--bg3/--border/--fg/--muted/--accent/--shadow) and the [data-theme="dark"] switch both drive. To place it on a page: include this file once, and give the menu row that opens it id="about-open". Everything else wires itself up. The facts come from the `about` context processor (starcubes.context_processors.about_info), so no view has to pass them. {% endcomment %}
