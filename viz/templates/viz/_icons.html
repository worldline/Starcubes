{% comment %} Inline SVG icon sprite — the whole icon vocabulary of the frontend. Included once per page directly after ; icons are then used as and sized by the `.ic` rule (1em square, so the button's font-size drives the icon). Every path is `fill: none; stroke: currentColor` — set on `.ic`, not here — which is why a symbol needs no dark-mode variant: it inherits the colour of whatever button it sits in, in either theme. Drawn by hand on a 24x24 grid in the Lucide idiom (1.75 stroke, round caps and joins, 2px+ margin). Not a dependency, not a font, not a licence question. Keep the ids `ic-*` and sorted; `sources/` is expected to include the same sprite eventually. {% endcomment %}
