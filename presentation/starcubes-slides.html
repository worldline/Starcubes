starcubes

Any SQL source → compact star schema → interactive timeseries

  • Problem: operational DBs hold rich transactional data, but querying them for trends is slow, complex, and risky
  • Solution: configure a datasource once — starcubes extracts, compresses, and loads it into Postgres; a chart UI renders it instantly
  • Sources supported: Oracle, PostgreSQL, MySQL, MSSQL — anything SQLAlchemy speaks
  • Self-contained: one Django app, one Postgres instance, no external queue or scheduler

  • One Postgres schema per datasource — incompatible shapes stay isolated
  • Metadata-driven: dimensions, measures, filters defined as DB rows, no code changes
  • Server-side plot cache keyed on sha256 of query parameters + epoch

Key Features

  • Three dimension modes: source-table lookup · inline CSV · auto-discovered at ETL time
  • Measure catalog: count, sum, avg, min, max, quantile-bands — pick style per measure
  • Chart UI: stacked bars · drill-down · AND/OR filter builder · follow mode (live seismograph pan)
  • GUI CRUD: datasource setup, ETL monitor with live progress, dimension inspection, partition lifecycle
  • Incremental ETL: high-watermark resumption, crash-safe deduplication, optional forever-loop daemon
