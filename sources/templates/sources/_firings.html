{% comment %} The firing-episode list, shared by the global page (sources/firings.html) and the per-datasource Firings tab (sources/detail.html). Both get their rows from views._firing_episodes and their context from views.firings_context, so the two views of the same episodes cannot drift. `scoped` is the only switch: on a datasource's own page there is nothing to pick a datasource with, so the dropdown becomes a link out to the global page and the Datasource column drops out of the table. The two filter links come in as url_all / url_open because each page filters within its own URL — the global page by `?show=`, the tab by reloading onto `?tab=firings`. Refresh names its URL for the same reason: an empty href reloads whatever the address bar holds, and the sub-tab was activated client-side without touching it. {% endcomment %}
