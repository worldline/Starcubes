{% comment %} The "Log Source" card, shared by new.html and edit.html. One partial rather than two copies because the two forms carry identical field names — the only difference is whether `ds` is in the context, and `|default:''` renders empty for a missing variable, which is exactly what the create form wants. Every element that belongs to one kind of source carries data-src-kind, and _logfile_js.html shows or hides them from the dialect dropdown. The SQL-only groups in the surrounding forms are marked the same way. The fields stay in the DOM when hidden rather than being removed, and that is deliberate: `source_new` reads `p["watermark_column"]` and `p["partition_column"]` as required index accesses, so a field missing from the POST is a MultiValueDictKeyError — a 500, not a 400. Hidden-but-present also means switching the dialect back and forth loses nothing typed. {% endcomment %}
Log Source
Every fact column is read from a named group of this pattern — (?P<name>…) — and a fact column's Source Expression holds the group's name instead of SQL. Anchors mean line boundaries (the pattern is compiled with re.MULTILINE). Press Probe to run it against the newest lines and have the columns proposed for you.
strptime format for the time group. Leave blank to auto-detect ISO-8601; @epoch / @epoch_ms for numeric stamps. A format without a year (syslog) takes the year from the file's modification time.
IANA name, applied only when the timestamp carries no offset — a %z in the line always wins. Blank means UTC. Nothing can detect a wrong value here: a naive timestamp carries no evidence about its zone, so a log written in local time and read as UTC is silently off by the offset. Set it to the zone the logging host runs in.
Optional. A line matching this begins a new record; one that matches neither this nor the Line Regex is appended to the record before it, which is how a multi-line stack trace stays a single row. Blank means one line is one record — which is every access-log format.
Blank means utf-8. Always read with errors=replace — one bad byte must not end a load.
Share of lines that must match the Line Regex. 0 disables it and lines that do not match are only counted. Set it and a changed log format ends the run failed with the rate in the error, instead of quietly dropping the row count. The refusal only applies while nothing has been loaded yet — failing later would leave the watermark behind and the next run would re-read the window, which without a primary key means duplicates.
