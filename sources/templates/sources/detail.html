    🔍 Gap Audit

    Run Audit counts rows on both sides per time bucket — cheap, and unbounded in window size, so it is the sweep that shows where to look. The source is counted on {{ ds.watermark_column }}, the fact table on {{ ds.watermark_fact_expr|default:ds.partition_column }}.

    Compare IDs pulls both primary-key sets and diffs them, naming the exact rows. Use it on a bucket the count flagged — or on one it did not, because counting has a blind spot: a window that lost 100 rows and had 100 deleted upstream nets to zero and reads as clean. It also finds duplicate PKs in fact, which counting cannot see at all. Bounded by memory, so keep the window tight.
